## 💻 Local Development Setup

To preview and run the website locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/FuadSaad/my-portfolio.git
   cd my-portfolio
   ```

2. **Start a local web server:**
   - Using Python:
     ```bash
     python -m http.server 3000
     ```
   - Using Node.js:
     ```bash
     npx serve .
     ```

3. **Open in browser:**
   ```
   http://localhost:3000
   ```
